Markdown 是一種純文字格式，可以被轉譯成結構化的 HTML。你在 `.md` 檔案裡用幾個
標點符號寫東西，任何轉譯器都能把它變成標題、清單、表格和連結。

它 2004 年由 John Gruber 創造。二十年後，它成了 README、文件、部落格、聊天訊息和
大型語言模型提示詞的預設格式。原因很簡單：它複製到哪裡都不會壞，而且即使沒有任何
東西轉譯它，原文依然是能讀的。

## 為什麼要用它

三個實在的理由：

1. **方便比對差異。** Word 檔案的 git diff 完全沒法看。Markdown 的 diff 能精確告訴你
   哪一句話改了。
2. **到處都能用。** 從 GitHub 到 Notion 到 ChatGPT，全都認它。
3. **寫得快。** 不用找工具列，不用動滑鼠，手不離鍵盤。

## 真正會用到的語法

掌握十條規則就夠用了。

### 標題

```markdown
# 一級標題
## 二級標題
### 三級標題
```

一級一個 `#`，後面**必須跟一個空格**。`#標題` 在大多數剖析器裡會被當成普通文字。

### 強調

```markdown
*斜體*  或  _斜體_
**粗體**  或  __粗體__
***粗斜體***
```

### 清單

```markdown
- 無序項
- 另一項
  - 巢狀項（破折號前空兩格）

1. 有序項
2. 第二項
```

巢狀靠縮排。無序空兩格，有序空三格。弄錯了會得到一串帶奇怪前導空格的平級清單。

### 連結與圖片

```markdown
[連結文字](https://example.com)
![替代文字](image.png)
```

唯一區別就是開頭那個 `!`。

### 程式碼

行內程式碼用單個反引號：`` `npm install` ``。

程式碼區塊用三個反引號，而且**一定要標註語言**：

````markdown
```javascript
const x = 1;
```
````

不標語言就沒有語法高亮。

### 引用

```markdown
> 被引用的文字
> 第二行
```

### 表格

```markdown
| 功能 | 狀態 |
| --- | --- |
| 匯出 | 已上線 |
| 匯入 | 測試中 |
```

`---` 那一行是必須的——它告訴剖析器哪一行是表頭。對齊方式用冒號控制：
`:---` 靠左，`---:` 靠右，`:---:` 置中。

## 幾個能坑掉新手一小時的地方

**每個區塊級元素前面都要有空行。** 下面這個不會轉譯成清單：

```markdown
一段文字
- 第一項
- 第二項
```

段落和清單之間必須空一行。標題、程式碼區塊、表格同理。

**用四個空格縮排也能表示程式碼區塊**，但混用 tab 和空格會壞掉。直接用三個反引號的
柵欄式區塊，徹底繞開這個問題。

**不同方言不一樣。** CommonMark 是標準，GitHub 風格（GFM）額外支援表格、任務清單
和自動連結。你的剖析器可能支援腳註，也可能支援公式，也可能都不支援。有東西轉譯
不出來，第一件事就是查方言。

**跳脫。** 想顯示字面意義的星號，寫 `\*`。需要跳脫的字元：
`\`` `*`` `_`` `{`` `}`` `[`` `]`` `(`` `)`` `#`` `+`` `-`` `.`` `!`
