Markdown の表は、構文全体の中で最も「静かに失敗する」部分です。エラーは出ず、
ただのプレーンテキストとして表示されます。ルールは多くありませんが、厳格です。

## 最小限の表

```markdown
| 列 A | 列 B |
| --- | --- |
| 値 1 | 値 2 |
```

要件は 3 つ：

1. セルは縦棒で区切る
2. **2 行目は区切り行**で、ハイフンとコロンだけにする
3. 先頭と末尾の縦棒は任意だが、表内で統一する

区切り行が無いと、縦棒付きのテキストが 4 行並ぶだけになります。これが表が失敗する
最も多い原因です。

## 配置

区切り行のコロンが列の配置を決めます：

```markdown
| 左寄せ | 中央 | 右寄せ |
| :--- | :----: | ----: |
| a    |   b    |     c |
```

- `:---` 左寄せ
- `:---:` 中央寄せ
- `---:` 右寄せ

ハイフンは 1 文字で十分です。`|:-|:-:|-:|` も有効です。

## 縦棒のエスケープ

セル内の縦棒を文字として出したい場合は必ず `\|` と書きます。さもないと後続の列が
すべてずれます：

```markdown
| 式 | 意味 |
| --- | --- |
| `a \| b` | ビット和 |
```

シェルコマンドや正規表現のドキュメントを書く人は特に踏みやすい罠です。どちらも
縦棒を多用するからです。

## できないこと

**セルの結合。** Markdown には `colspan` にも `rowspan` にも対応する構文がなく、
結合は完全に不可能です。内容を繰り返すか、HTML の表を直接書くのが一般的な回避策
です。

**複数行セル。** 1 つのセルに改行を入れられません。必要なら、HTML の `<br>` を使う
（多くの方言で有効）か、表の構造自体を見直してください。

**ネストした表。** 非対応です。

**長い内容。** 表はきれいに折り返してくれません。段落丸ごと入ったセルは読めたもの
ではなくなります。リストを使いましょう。

## 形式をまたいで表を運ぶ

ここが一番時間を食う部分です。よくある方向は 3 つ：

**CSV → Markdown。** 厄介なのは区切り文字の判定と引用符付きフィールドです。カンマを
含むセルは `"Smith, John"` のように引用符で囲まれます。`split(',')` では 2 列に
割れてしまいます。ちゃんとしたパーサーを使う必要があります。

**JSON → Markdown。** フラットなオブジェクトの配列はきれいに対応します。キーが
ヘッダー、値がセルになります。ネストしたオブジェクトは全く対応できません。
ドット連結（`user.name`）などで事前にフラット化してください。

**Markdown → CSV。** 読み取りは逆操作ですが、カンマや引用符を含む値を再エスケープ
する必要があります。エスケープ方針なしに CSV を書くと、Excel で開いたときに
レイアウトが崩れます。

この 3 つにはブラウザーで動くツールがあります：
[CSV → Markdown 表](/ja/csv-to-markdown-table/)、
[JSON → Markdown 表](/ja/json-to-markdown-table/)、
[Markdown 表 → CSV](/ja/markdown-table-to-csv/)。

## 表を紙に載せる

列の多い表は PDF の古典的な難問です。10 列の表を A4 縦に置いても読めません。

対策は 2 つ、どちらも CSS 1 行です：

```css
@page { size: A4 landscape; }
```

または表内のフォントサイズを落として折り返しを許可する：

```css
table { font-size: 9pt; }
tr { break-inside: avoid; }   /* 1 行を 2 ページに分割しない */
```

[Markdown 表 → PDF](/ja/markdown-table-to-pdf/) は既定で横向きレイアウトを使います。

## トラブルシュート

表がプレーンテキストとして表示される場合、順に確認してください：

1. ヘッダーのすぐ下にハイフンだけの区切り行があるか？
2. 表の前後に空行があるか？
3. 各列の縦棒の数はヘッダーと一致しているか？
4. 文字としての縦棒を `\|` にエスケープしたか？
5. そもそもパーサーが表に対応しているか？（最初の Markdown も CommonMark も表に
   非対応です。表は GFM の拡張です。）
